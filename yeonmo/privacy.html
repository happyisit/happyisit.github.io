앱은 회원가입이 없고, 개발자는 이용자의 정보를 받는 서버를 운영하지 않습니다. 이용자가 앱에 입력하거나 붙여 넣은 글, 만든 비밀번호, 그린 그림은 기기 안에서만 처리되며 개발자에게 전송되지 않습니다.

2. 기기에만 저장하는 정보

앱은 기능 제공을 위해 다음 정보를 이용자의 기기(앱 전용 저장공간)에만 저장하며, 개발자는 이 정보에 접근할 수 없습니다.

- 날짜 기준 시간대: 처음 실행할 때 기기 시간대를 바탕으로 정하며, 매일 지급·광고 횟수 계산에 사용합니다.

- 에너지 정보: 에너지 잔량, 지급 날짜, 광고 시청 횟수와 시각, 최근 며칠 동안 받은 에너지 기록

- 히스토리: 수익률 계산기·바코드 생성기·QR코드 생성기·계산기를 직접 실행했을 때의 입력값과 결과 요약 (설정에서 저장을 끄거나 모두 지울 수 있습니다)

Политика конфиденциальности Yeonmo

HappyisIT (далее — «Разработчик») бережно относится к персональным данным пользователей мобильного приложения Yeonmo (далее — «Приложение») и устанавливает настоящую политику в соответствии с применимым законодательством.

1. Основные принципы

В Приложении нет регистрации, и Разработчик не использует серверы, принимающие информацию пользователей. Текст, который вы вводите или вставляете, созданные пароли и наброски обрабатываются только на вашем устройстве и никогда не передаются Разработчику.

2. Информация, хранящаяся только на устройстве

Для работы функций Приложение хранит следующую информацию только на вашем устройстве (в закрытом хранилище Приложения). Разработчик не имеет к ней доступа.

- Настройки: язык интерфейса, настройки безопасности (блокировка устройства, запрет скриншотов), сохранение истории, просмотр вводного экрана, факт и версия принятых условий

- Информация для удобства: избранные и недавно использованные инструменты

- Часовой пояс для дат: определяется по часовому поясу устройства при первом запуске и используется для расчёта ежедневных подарков и количества просмотров рекламы

- Сведения об энергии: остаток, дата начисления, количество и время просмотров рекламы, журнал полученной энергии за последние дни

- История: ввод и краткий результат при запуске калькулятора изменения, генератора штрихкодов, генератора QR-кодов или калькулятора (можно отключить или очистить в настройках)

- Значения целостности: случайное значение для устройства и подпись для проверки, не изменялись ли сохранённые файлы вне Приложения

Эта информация хранится до её удаления вами, очистки данных Приложения или его удаления — тогда она удаляется.

3. Информация, которая не сохраняется

Не сохраняются пароли для QR-кодов Wi-Fi, пароли из генератора, данные тела для расчёта ИМТ и процента жира, наброски и текст, введённый в текстовые инструменты; всё это исчезает при закрытии Приложения. Биометрические данные (отпечатки, лицо) обрабатывает операционная система устройства; Приложение получает только результат проверки.
